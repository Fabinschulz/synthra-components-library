# UI Kit - ReactJS & MUI
![Componente React](./assets/react-component-libraries.webp)

## Overview

### Este projeto é um kit de componentes de interface de usuário (UI Kit) desenvolvido com React e Material-UI (MUI). Ele oferece uma coleção de componentes reutilizáveis, estilizados e prontos para serem integrados em projetos de aplicações web, proporcionando uma experiência de desenvolvimento mais eficiente e consistente.

## Recursos

- Componentes reutilizáveis: Botões, Inputs, Selects, Tabelas, etc.
- Estilização consistente com Material-UI
- Suporte a acessibilidade
- Documentação detalhada

## Uso

```javascript
import { Button } from '@paipe/design-system';

function App() {
  return (
    <Button color="primary" onClick={() => {}} size="medium" variant="contained">
      Submit
    </Button>
  );
}
```

# Fluxo de Pull Request

Antes de criar um PR, siga os seguintes passos:

1. Execute o comando `changeset`
2. Execute o comando `version-packages`
3. Adicione e commite as mudanças
4. Dê push para o repositório
